# Жанры, помощники и порядок работы

## Выбор жанра

Определи жанр по запросу. Если жанр неясен, возьми «ответ в чате». Если пользователь назвал уровень, он важнее колонки «Уровень по умолчанию».

| Жанр | Помощник (если установлен) | Уровень по умолчанию |
|---|---|---:|
| Ответ или объяснение в чате | — | 80 |
| Инструкция, runbook, процедура, сообщение об ошибке, релиз-ноты, коммит | `simple-english` (англ.), `ru.md` (рус.) | 100 |
| README, документация, описание API, отчёт об инциденте | `simple-english` (англ.), `ru.md` (рус.) | 80 |
| Дизайн-док, спецификация, RFC: «сожми», «сократи» | `lossless-doc-compress` | 80 |
| Текст интерфейса: кнопки, ошибки, формы, уведомления | `ux-copy` | 80 |
| Письмо, сообщение, отчёт | — | 60 |
| Статья, лонгрид, колонка | `statya`, затем `redaktura` | 60 |
| Правка чужого русского текста | `redaktura` | 60 |
| Пост для соцсети, рассылка | `post` | 40 |
| Лендинг, «о себе», пресс-релиз, страница компании | `promo` | 40 |
| Стиль и словарь проекта, «редполитика» | `redpolitika` | — |
| Проза, стихи, сценарий | Ничего не применяй. Включай только A по просьбе. | 20 |

Нет помощника — применяй `levels.md` и справочник языка сам.

## Порядок работы

1. **Определи рамку.** Язык, жанр, читатель, уровень. Спрашивай только то, без чего текст получится неверным. Одного вопроса обычно достаточно.
2. **Проверь контекст проекта.** Есть `.agents/redpolitika.md` — прочитай. Его словарь и запретные слова важнее моих.
3. **Собери факты.** Дыру в фактуре закрой вопросом, не выдумкой (A9).
4. **Напиши черновик.** Загрузи помощника из таблицы, если он есть. Применяй правила своего уровня.
5. **Сожми.** Убери то, что можно убрать без потери смысла (см. ниже).
6. **Проверь.** Пройди чек-лист из `SKILL.md`. Если можешь запустить Python, запусти `scripts/antislop_lint.py`.
7. **Отдай текст.** Без рассказа о том, какие правила ты применил. Уровень назови одной строкой только в документе длиннее экрана.

## Сжатие без потерь

Сжатие — шаг 5. Его глубина зависит от размера.

- **Короткий текст или ответ в чате.** Сожми молча: убери воду, оговорки, пересказ, ритуальные начало и конец. Журнала не нужно.
- **Документ, который просят сжать, или текст длиннее примерно 500 слов.** Загрузи `lossless-doc-compress` целиком. Он замеряет слова до и после, ведёт журнал удалений и ставит пометки FLAG на спорные места. Главное правило оттуда: сомневаешься — пометь, не режь.

Что считается «без потерь»: факты, числа, решения и их причины, оговорки, ограничения, имена, код и таблицы остаются. Убирается только пустое: вода, оговорки без содержания, шаблонные вступления, повторы, многословные формулы с точным коротким эквивалентом.

Сжатие не равно короткому тексту любой ценой. Redaktura предупреждает: цель — самый полезный текст, а не самый короткий. Не вырезай примеры и детали, которые делают текст понятным.

## Как поддерживать связь с помощниками

- Помощники ставятся вместе с этим навыком, но они независимы. Каждый может сработать сам по своему описанию.
- Если сработал помощник, действуй по его процессу, а уровень и разрешение конфликтов бери отсюда (`conflicts.md`).
- `statya`, `post`, `promo`, `ux-copy` ссылаются на `../redaktura/references/*`. Не разделяй эти папки при ручной установке.

## Файл `.agents/redpolitika.md`

Его создаёт `redpolitika`. Он хранит читателя, площадки, регистр, словарь и запретные слова проекта. Пользователь, который регулярно пишет для одного проекта, выигрывает от этого файла. Если файла нет и пользователь пишет часто, один раз предложи его создать.
