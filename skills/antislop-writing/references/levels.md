# Лестница уровней

Один ползунок задаёт строгость: 20, 40, 60, 80 или 100. Правило включается с «своего» уровня и действует выше. Правило «с 60» работает на 60, 80 и 100.

Любое число округляй к ближайшей ступени. При равенстве округляй вниз: «на 90%» значит 80.

## Ступени

| Уровень | Название | Для чего | Как читается |
|---:|---|---|---|
| 100 | Строго | Процедуры, где ошибка дорога: runbook, инструкция, безопасность, текст на перевод | Как документация: ровно, без украшений |
| 80 | Почти строго | Ответы, объяснения, README, документация. **По умолчанию** | Ясно и сухо, но не механически |
| 60 | Ясно | Письма, отчёты, статьи | Хороший редакторский текст |
| 40 | Живо | Посты, рассылки, промо, эссе | Голос автора важнее ограничений |
| 20 | Минимум | Авторская проза | Только убрать штампы и пустые слова |

Предел длины предложения: 100 → 20 слов, 80 → 25, 60 → 30, 40 → 40, 20 → без предела.

## Откуда это

- В посте Карпати есть одна идея: просить «80% of the way to ASD-STE100», потому что стандарт очень жёсткий. Ступени, числа на них и состав правил придумал автор этого репозитория.
- Числа 25, 30 и 40 слов — калибровка автора, в стандартах их нет.
- Числа 20 слов, «шесть предложений в абзаце» и «одно предложение-абзац на десять» взяты из ГОСТ Р 58049-2017 и ASD-STE100. Они действуют на уровне 100.

Метки источников: **УТР** — ГОСТ Р 58049-2017, пункт; **SE** — навык `simple-english` (ASD-STE100), D — раздел «Document», R — раздел «Reply»; **Ред** — `redaktura-skills`; **LDC** — `lossless-doc-compress`; **авт.** — решение автора.

## Правила

### A. Антислоп: с 20

| ID | Правило | Источник |
|---|---|---|
| A1 | Суть в первой фразе. Без приветствия, пересказа вопроса, разгона и прощания. | SE:R2, SE:R5, Ред: следы нейросети |
| A2 | Факт вместо оценки. Без «важный», «ключевой», «мощный», «уникальный», «очень», «крайне». Нужна оценка — назови основание или число. | Ред: слово, оценки; SE:D10 |
| A3 | Без ярлыков-анонсов: «Важный нюанс», «Честная оговорка», «Самое интересное дальше». Оставь само содержание. | Ред: следы нейросети |
| A4 | «Не X, а Y»: не больше одной на 1000 слов, не в начале абзаца, не в соседних абзацах. «Это не про X, это про Y» — никогда. Фактические отрицания («Сервис не хранит пароли») можно. | Ред: следы нейросети |
| A5 | Без канцелярита и штампов: «является», «осуществлять», «данный», «в рамках», «в целях», «на сегодняшний день», «в современном мире», «играет важную роль». | Ред: слово |
| A6 | Без каскада оговорок («может быть», «как правило», «во многом»). Настоящую неопределённость оставь одной оговоркой. | Ред; LDC: hedging |
| A7 | Без формульных концовок: «в заключение», «таким образом», мораль, итог, который повторяет текст, «надеюсь, помогло». | Ред; SE:D10; LDC: slop |
| A8 | Без декора: эмодзи вместо маркеров, **жирные лид-ины**, заголовок над двумя предложениями, тройки «быстро, удобно и надёжно». | Ред: декор; SE:D11 |
| A9 | Не выдумывай факты, цифры, ссылки и цитаты. Нет данных — скажи или спроси автора. | Ред; SE:D2; LDC |
| A10 | Не трогай код, команды, имена, пути, числа, цитаты, ссылки. | SE:D2; LDC: sacred |
| A11 | Одну мысль скажи один раз. Пересказ уже сказанного убери. | LDC: restatement |
| A12 | Предупреждения о безопасности, тексты ошибок и подтверждения опасных действий не сокращай. | SE:R6; LDC |

### B. Ясность: с 40

| ID | Правило | Источник |
|---|---|---|
| B1 | Действует человек, а не процесс. «Бухгалтер готовит документы», не «осуществляется подготовка». | Ред: предложение; УТР 8.2.3.3 |
| B2 | Действительный залог. Исполнитель не важен — неопределённо-личная форма: «Пароль хранят в хеше», не «хранится». | УТР 8.2.3.3, 8.2.3.13 |
| B3 | В предложении не больше трёх сущностей, требующих внимания. | Ред: предложение |
| B4 | Причастный и деепричастный оборот перестрой в два предложения или придаточное. | Ред; УТР 8.2.3.11 |
| B5 | Один абзац — одна мысль. Суть в первой фразе. | Ред; УТР 8.2.6.2 |
| B6 | Термин объясни при первом употреблении, не больше десяти слов. Аббревиатуру раскрой. Общеизвестное не объясняй. | Ред; SE:D9; УТР 8.2.3.8 |
| B7 | Вертикальный список — для трёх и более однородных пунктов или шагов. | УТР 8.2.3.16; SE:D11 |
| B8 | Чередуй длину предложений: не три коротких подряд, не пять длинных. На 100 не требуется. | Ред: ритм |
| B9 | Без вводных слов-паразитов: «кстати», «собственно», «как известно», «стоит отметить». | Ред: слово |
| B10 | Предложение до 40 слов. | авт. |

### C. Контролируемый язык: с 60

| ID | Правило | Источник |
|---|---|---|
| C1 | Прямой порядок слов: подлежащее, сказуемое, дополнение. | УТР 8.2.3.4 |
| C2 | Одно понятие — одно слово на весь текст. Не меняй термин ради красоты. | УТР 8.2.3.7; SE:D8 |
| C3 | Не больше двух существительных в родительном подряд. Глагол вместо отглагольного существительного: «проверьте», не «проведите проверку». | УТР 8.2.3.10; SE:D8 |
| C4 | Условие раньше действия: «Если сборка упала, откройте журнал». | SE:D3; УТР 8.2.7 |
| C5 | Конкретика: назови объект, место, значение. Не «настройте систему», а «задайте `timeout` в `config.yaml`». | УТР 8.2.5.4; SE:D9 |
| C6 | Предложение до 30 слов. | авт. |

### D. Строго: с 80

| ID | Правило | Источник |
|---|---|---|
| D1 | Предложение до 25 слов. | авт. |
| D2 | Инструкция: императив во множественном числе, глагол первым. «Откройте файл», не «Необходимо открыть», не «Открой». | УТР 8.2.3.9, 8.2.5.3 |
| D3 | Одно действие — одно предложение. Два действия вместе — только если они одновременны. | УТР 8.2.5.2 |
| D4 | Предупреждение: сначала команда или условие, потом риск. «Не запускайте на проде. Команда удаляет строки.» | УТР 8.2.7; SE:D12 |
| D5 | Без метафор, сравнений и сленга. Профессиональный термин — не сленг. | УТР 8.2.3.5 |
| D6 | Равнозначное русское слово вместо иностранного: «внедрить», не «имплементировать». Термины отрасли из глоссария остаются. | УТР 8.2.3.6 |
| D7 | Абзац до шести предложений. | УТР 8.2.6.2; SE:D1 |
| D8 | Простые времена: прошедшее для событий, настоящее для описаний. Будущее — для обещания, которое сбудется. | Ред: тональность; SE:D4 |
| D9 | Ответ в чате — проза. Список только для шагов и трёх и более однородных пунктов. Без заголовков в коротких ответах, без жирного. | SE:R1 |

### E. Полный УТР/STE: с 100

| ID | Правило | Источник |
|---|---|---|
| E1 | Предложение до 20 слов, в инструкциях и в описаниях. | УТР 8.2.5.1, 8.2.6.1; SE:D1 |
| E2 | Если в тексте больше трёх терминов, которых читатель может не знать, начни с глоссария и держись его. Нет готового — собери из текста. В коротком тексте объясни термин при первом употреблении, без отдельного глоссария. Не повторяй в глоссарии то, что скажешь в тексте. | УТР 8.1.3–8.1.9 |
| E3 | Абзац из одного предложения — не чаще одного на десять абзацев. | УТР 8.2.6.2 |
| E4 | Скобки — для ссылок, обозначений и уточнений, не для мыслей. | УТР 8.2.3.17 |
| E5 | Не опускай слова, если смысл искажается. Сокращай слова только там, где смысл ясен. | УТР 8.2.3.15 |
| E6 | Ответ в чате без списков (кроме шагов), без заголовков, без жирного. Проза и блоки кода. | SE:R1 |
| E7 | Английский: словарь STE из режима Strict навыка `simple-english`. | SE: Strict |
| E8 | Не пиши «кнопка» и «ссылка», если название элемента ясно: «Нажмите «Сохранить»». | УТР 8.2.3.18 |

### EN. Английские правила: с 80

Правила, которых нет в русском: запрет `should/would/may/might/could`, сокращений (`don't`), em-dash, точки с запятой и оборота «-ing после запятой». Они описаны в `en.md`. Линтер помечает их кодом `EN`.

## Как считать слова

Правило УТР 8.2.5.1: число — одно слово. Буквенно-цифровой идентификатор и аббревиатура — по одному слову. Название, предупредительная надпись и цитата — по одному слову. Текст в скобках считай отдельным предложением. Код и пути — по одному слову.

## Пример

Иллюстрация составлена вручную, чтобы показать разницу ступеней. Это не замер модели.

Исходник:

> Перезапуск сервиса, выполняемый после обновления конфигурации, позволяет применить изменения, которые были внесены администратором, и тем самым избежать ситуации, при которой система продолжает работать со старыми настройками, словно «застрявшая в прошлом».

| Уровень | Результат |
|---:|---|
| 100 | Администратор изменил конфигурацию. Перезапустите сервис. Без перезапуска сервис работает со старыми настройками. |
| 80 | После изменения конфигурации перезапустите сервис. Без перезапуска он продолжит работать со старыми настройками. |
| 60 | Администратор изменил конфигурацию, поэтому сервис нужно перезапустить: пока он не перезапущен, он использует старые настройки. |
| 40 | Поменяли конфигурацию — перезапустите сервис, иначе он останется со старыми настройками. |
| 20 | Перезапуск сервиса после обновления конфигурации применяет изменения администратора. Без него система продолжает работать со старыми настройками. |
