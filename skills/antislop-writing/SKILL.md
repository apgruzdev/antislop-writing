# Antislop writing

Цель: читатель понимает текст с первого раза и не видит в нём нейрослопа. Навык собирает четыре источника в один ползунок «уровень». Уровень решает, насколько строго их применять.

Источники и авторы: `THIRD_PARTY.md` в корне репозитория. Спорные места между источниками: `references/conflicts.md`.

## 1. Определи рамку

1. Язык. Пиши на языке запроса. Для русского прочитай `references/ru.md`, для английского `references/en.md`.
2. Жанр. Найди его в таблице `references/genres.md`. Таблица называет помощника и уровень по умолчанию.
3. Уровень. Бери первое найденное:
   1. число или слово в запросе: «на 60%», «level 100», «строго» — 100, «почти строго» — 80, «ясно» — 60, «живо» — 40, «минимум» — 20;
   2. строка `Уровень письма: N` в `AGENTS.md`, `CLAUDE.md` или `GEMINI.md`;
   3. значение для жанра из таблицы;
   4. 80.

   Число округляй к ближайшей ступени. При равенстве округляй вниз.
4. Проект. Есть `.agents/redpolitika.md` — прочитай его. Словарь и запреты проекта важнее моих.

## 2. Ступени

| Уровень | Название | Предложение | Для чего |
|---:|---|---:|---|
| 100 | Строго | до 20 слов | Процедуры, runbook, безопасность, текст на перевод |
| 80 | Почти строго | до 25 | Ответы, объяснения, README, документация. **По умолчанию** |
| 60 | Ясно | до 30 | Письма, отчёты, статьи |
| 40 | Живо | до 40 | Посты, рассылки, промо |
| 20 | Минимум | без предела | Авторская проза: только убрать штампы |

Полная лестница правил с номерами и источниками: `references/levels.md`. Читай её, когда проверяешь чужой текст или сомневаешься в правиле.

## 3. Ядро: на любом уровне

- Первая фраза даёт ответ или суть. Без приветствия, пересказа вопроса, разгона и прощания (A1).
- Факт вместо оценки. Нет «важный», «ключевой», «мощный», «очень». Есть число — дай число (A2).
- Нет ярлыков «Важный нюанс», «Честная оговорка» и указок «Самое интересное дальше» (A3).
- «Не X, а Y» — не больше одного раза на 1000 слов. «Это не про X, это про Y» — никогда (A4).
- Нет канцелярита и штампов: «является», «осуществлять», «данный», «в рамках», «в современном мире» (A5).
- Нет каскада оговорок. Настоящую неопределённость оставь одной оговоркой (A6).
- Нет формульной концовки, морали и итога, который повторяет текст (A7, A11).
- Нет декора: эмодзи, жирных лид-инов, троек прилагательных, заголовка над двумя предложениями (A8).
- Не выдумывай факты, цифры, ссылки и цитаты. Нет данных — скажи или спроси (A9).
- Код, команды, имена, пути, числа, цитаты не трогай. Предупреждения о безопасности и тексты ошибок не сокращай (A10, A12).

## 4. Что добавляют уровни

- С 40. Действует человек, а не процесс. Действительный залог. Не больше трёх сущностей в предложении. Причастные обороты в два предложения. Термин объясни при первом употреблении. Чередуй длину предложений.
- С 60. Прямой порядок слов. Одно понятие — одно слово. Не больше двух существительных в родительном подряд. Условие раньше действия. Конкретика вместо «настройте систему».
- С 80. Инструкция: императив во множественном числе, глагол первым, одно действие в предложении. Предупреждение: сначала команда, потом риск. Без метафор и сленга. Абзац до шести предложений. Ответ в чате — проза, список только для шагов и трёх и более однородных пунктов. Английский: без `should/may`, без сокращений, без em-dash.
- На 100. Предел 20 слов. Глоссарий в начале — только если в тексте больше трёх терминов, которых читатель может не знать; иначе объясни термин при первом употреблении. Каждое действие и предупреждение скажи один раз. Без вводных слов. Ответ без заголовков и жирного. Английский: режим Strict навыка `simple-english`.

## 5. Порядок работы

1. Определи рамку (шаг 1). Вопрос задавай, только если без ответа текст получится неверным.
2. Собери факты. Дыру закрой вопросом, не выдумкой.
3. Напиши черновик. Загрузи помощника из таблицы жанров, если он установлен.
4. Сожми: убери воду, пересказ, пустые оговорки. Короткий текст сжимай молча. Документ длиннее 500 слов или просьбу «сожми» отдай навыку `lossless-doc-compress`.
5. Проверь по списку ниже.
6. Отдай текст. Не рассказывай, какие правила применил. Уровень назови одной строкой только в длинном документе.

Если сработал другой навык из набора, веди работу по его процессу, а уровень и разрешение конфликтов бери отсюда.

## 6. Проверка перед выдачей

1. Три самых длинных предложения: в пределе уровня? Если нет, раздели.
2. Первая фраза отвечает на вопрос?
3. Нет ли слов из ядра (шаг 3)? Найди «является», «данный», «в рамках», «важно понимать», «не просто».
4. Каждое число, имя и ссылка есть в источнике? Выдуманных нет?
5. Термины одинаковы по всему тексту? Новый термин объяснён?
6. Код, команды и цитаты не изменились?
7. Можно запустить Python? Выполни `python3 scripts/antislop_lint.py --level N файл.md` (для ответа в чате добавь `--mode reply`). Линтер ловит механику: длину, шаблоны, декор. Смысл он не проверяет.

## 7. Режим проверки чужого текста

Если просят проверить текст, не переписывай его целиком. Запусти линтер, затем выдай таблицу: номер правила, фрагмент, исправление. Номера бери из `references/levels.md`, не по памяти. Полную версию дай, если пользователь просит переписать.

## 8. Границы

- Навык не сертифицирует соответствие ASD-STE100 или ГОСТ. Закрытого словаря для русского нет.
- Цель — читаемый текст, а не обход детекторов ИИ. Детекторы ненадёжны.
- Не применяй к прозе, стихам и юридическим формулировкам, где важна точная форма. Для прозы включай только ядро по просьбе.
- Правило, которое вредит читателю в этом тексте, не применяй. Правила — инструмент.

## Справочники

- `references/levels.md`: лестница правил A–E с источниками, как считать слова, пример по ступеням.
- `references/ru.md`: упрощённый технический русский язык и русские особенности.
- `references/en.md`: английские правила и связь с `simple-english`.
- `references/genres.md`: жанры, помощники, порядок работы, сжатие.
- `references/tells.md`: каталог нейрослопа с примерами.
- `references/conflicts.md`: где источники спорят, чем мы их разводим, чего не берём.
- `scripts/antislop_lint.py`: линтер.
