# antislop-writing

Набор навыков для AI-агентов против нейрослопа. Агент пишет по-русски (и по-английски) короче, яснее и без шаблонных оборотов. Строгость регулирует ползунок от 20 до 100%.

[English](README.en.md) · [Первоисточники](THIRD_PARTY.md) · [Результаты проверки](examples/eval/README.md)

Идея из [поста Андрея Карпати](https://x.com/karpathy/status/2105819303471976479): просить модель писать в духе ASD-STE100 и смягчать стандарт («80% of the way to ASD-STE100»), потому что он жёсткий. Репозиторий собирает вокруг этой идеи четыре источника в один набор:

| Что | Откуда |
|---|---|
| Контролируемый английский (ASD-STE100) | навык `simple-english`, [AminBlg](https://github.com/AminBlg/SimpleEnglish) |
| Упрощённый технический русский | [ГОСТ Р 58049-2017](https://meganorm.ru/Data/661/66114.pdf), раздел 8.2 |
| Русская редактура и следы нейросети | [redaktura-skills](https://github.com/N1arko/redaktura-skills), Людмила Сарычева и Никита Архипов |
| Сжатие без потери смысла | [lossless-doc-compress](https://github.com/ML-SystemDesign/MLSystemDesign/tree/main/skills/lossless-doc-compress), Babushkin и Kravchenko |

Связку и ползунок добавляет навык `antislop-writing`. Остальные восемь навыков лежат в репозитории копиями без изменений, чтобы одна установка ставила всё.

## Установка

```bash
npx github:apgruzdev/antislop-writing
```

Команда делает две вещи.

1. Ставит девять навыков в агентов, которые найдёт на машине: Claude Code, Codex, OpenCode, Gemini CLI, Cursor, GitHub Copilot, Windsurf и другие. Всего поддержано больше 70 агентов через [`skills`](https://github.com/vercel-labs/skills).
2. Добавляет в глобальные инструкции агентов короткое правило «всегда включено» (1,8 тыс. знаков). Оно напоминает агенту вызывать навык при любом тексте и держит самые важные правила, даже если навык не загрузился.

Ваш текст в этих файлах она не меняет: блок стоит между пометками `antislop-writing:begin` и `antislop-writing:end`. В каталоги агентов, которых у вас нет, она не пишет. После установки перезапустите агента.

Нужен Node.js 18+ и git. Сборщик навыков `npx skills` отправляет анонимную статистику; отключить: `DISABLE_TELEMETRY=1`.

Другие варианты:

```bash
npx github:apgruzdev/antislop-writing --level 60        # другой уровень (по умолчанию 80)
npx github:apgruzdev/antislop-writing --project         # для текущего проекта: ./AGENTS.md и навыки в проекте
npx github:apgruzdev/antislop-writing --skills-only     # без правила «всегда включено»
npx github:apgruzdev/antislop-writing --dry-run         # показать, что будет сделано
npx github:apgruzdev/antislop-writing status            # что установлено
npx github:apgruzdev/antislop-writing uninstall         # убрать всё
```

Только навыки, без установщика. `npx skills add apgruzdev/antislop-writing` покажет выбор агентов. Не используйте `--all`: он создаёт каталоги для всех 79 агентов, даже не установленных.

Плагин Claude Code. Хук `SessionStart` сам подгружает правило, обновления идут через marketplace:

```bash
claude plugin marketplace add apgruzdev/antislop-writing
claude plugin install antislop-writing@antislop-writing
```

Уровень в плагине: переменная `ANTISLOP_LEVEL=60` или файл `~/.config/antislop-writing/level`. Выберите одно: плагин или `npx skills`. Вместе они покажут навыки дважды.

Claude Desktop. У приложения две части, и установка у них разная.

- Вкладка Code — это Claude Code внутри приложения. Она читает те же `~/.claude/skills`, плагины и `CLAUDE.md`. Выполните в терминале `npx github:apgruzdev/antislop-writing` и перезапустите приложение. Плагин тоже подходит: поставьте его командами `claude plugin` выше.
- Вкладки Chat и Cowork берут навыки из аккаунта claude.ai, а не из `~/.claude`. Нужна загрузка ZIP. Соберите архивы (на macOS и Linux):

  ```bash
  git clone https://github.com/apgruzdev/antislop-writing && cd antislop-writing/skills
  for d in */; do zip -rqX "${d%/}.zip" "$d" -x "*.DS_Store"; done
  ```

  Затем в приложении: Customize → Skills → «+» → Create skill → Upload a skill, и загрузите `antislop-writing.zip`. Остальные восемь по желанию, каждый отдельным архивом. Для Free, Pro и Max включите Code execution and file creation в Settings → Capabilities: без этого навыки не работают. Откройте новый чат. Правило «всегда включено» вставьте из [`prompts/mini.md`](prompts/mini.md) в личные предпочтения.

Названия пунктов меню меняются между версиями приложения. Актуальные шаги: [справка Anthropic](https://support.claude.com/en/articles/12512180-use-skills-in-claude). Структура архива и валидность проверены по их требованиям (`skills-ref validate`). Сами архивы в аккаунт не загружались. `antislop-writing` работает и без остальных навыков. Работает ли ссылка `../redaktura/references/…` у `statya`, `post`, `promo` и `ux-copy`, когда навыки загружены порознь, не проверено.

Платформы без навыков (ChatGPT, веб-версии Claude и Gemini). Вставьте [`prompts/mini.md`](prompts/mini.md) в пользовательские инструкции. Он занимает 817 знаков и влезает в лимит ChatGPT Free (1500). Полная версия: [`prompts/kernel.md`](prompts/kernel.md) (1,8 тыс. знаков).

## Как пользоваться

Ничего вызывать не нужно. Просите текст, как обычно. Уровень можно назвать в запросе:

- «Объясни, что такое идемпотентность, на 100%».
- «Перепиши этот абзац по ГОСТ».
- «Сократи дизайн-док без потерь».
- «Убери нейрослоп из черновика, уровень 60».
- «Проверь текст» (агент запустит линтер и вернёт таблицу замечаний).

Уровень по умолчанию 80. Сменить навсегда: `--level N` при установке или число после «Уровень письма:» в файле инструкций.

## Ползунок строгости

Правила названы буквами A–E. Каждое включается со «своего» уровня и действует выше.

| Уровень | Название | Для чего | Предложение |
|---:|---|---|---:|
| 100 | Строго | Процедуры, runbook, безопасность, текст на перевод | до 20 слов |
| **80** | **Почти строго** | Ответы, объяснения, README, документация | до 25 |
| 60 | Ясно | Письма, отчёты, статьи | до 30 |
| 40 | Живо | Посты, рассылки, промо | до 40 |
| 20 | Минимум | Авторская проза: только убрать штампы | без предела |

- A (с 20): ответ в первой фразе, факт вместо оценки, без ярлыков «важный нюанс», без «не X, а Y» чаще раза на 1000 слов, без канцелярита, штампов, морали в конце, декора. Не выдумывать факты.
- B (с 40): действует человек, а не процесс; причастные обороты в два предложения; термин объясняется при первом употреблении.
- C (с 60): прямой порядок слов, один термин на понятие, условие раньше действия, конкретика.
- D (с 80): императив во множественном числе в инструкциях, предупреждение «сначала команда, потом риск», абзац до шести предложений, в чате проза.
- E (на 100): предел 20 слов, глоссарий, строгий словарь STE для английского.

Один абзац на всех уровнях (иллюстрация, написана вручную):

> **Исходник:** Перезапуск сервиса, выполняемый после обновления конфигурации, позволяет применить изменения, которые были внесены администратором, и тем самым избежать ситуации, при которой система продолжает работать со старыми настройками, словно «застрявшая в прошлом».
>
> **100:** Администратор изменил конфигурацию. Перезапустите сервис. Без перезапуска сервис работает со старыми настройками.
> **80:** После изменения конфигурации перезапустите сервис. Без перезапуска он продолжит работать со старыми настройками.
> **40:** Поменяли конфигурацию — перезапустите сервис, иначе он останется со старыми настройками.

Полная лестница с номерами правил и источником каждого: [`levels.md`](skills/antislop-writing/references/levels.md). Числа 25, 30 и 40 слов выбраны автором репозитория. В стандартах их нет.

## Что внутри

| Навык | Роль | Автор |
|---|---|---|
| **`antislop-writing`** | Связка: определяет язык, жанр и уровень, ведёт работу, вызывает помощников, проверяет | этот репозиторий |
| `simple-english` | Английский по ASD-STE100: режимы Plain и Strict | AminBlg, MIT |
| `redaktura` | Редактура русского текста в семь проходов, каталог следов нейросети | Сарычева, Архипов, CC BY 4.0 |
| `statya` | Статья с нуля | то же |
| `post` | Короткие посты | то же |
| `promo` | Лендинги, «о себе», пресс-релизы | то же |
| `ux-copy` | Тексты интерфейса | то же |
| `redpolitika` | Файл со стилем проекта `.agents/redpolitika.md` | то же |
| `lossless-doc-compress` | Сжатие документа без потери фактов, с журналом удалений | Babushkin, Kravchenko, MIT |

```
запрос на текст
  └─ правило «всегда включено» напоминает про навык
       └─ antislop-writing
            ├─ рамка: язык, жанр, читатель, уровень
            ├─ помощник по жанру: simple-english / statya / post / promo / ux-copy / redaktura
            ├─ ядро A + правила своего уровня
            ├─ сжатие: молча в коротком тексте, lossless-doc-compress в документе
            └─ проверка: список + scripts/antislop_lint.py
```

Где источники спорят (тире в русском, повелительное наклонение, длина против ритма, сжатие против «не пересушивай»), решения собраны в [`conflicts.md`](skills/antislop-writing/references/conflicts.md).

### Линтер

`skills/antislop-writing/scripts/antislop_lint.py`: Python 3, без зависимостей. Считает слова по правилам ГОСТ (число и цитата — одно слово, текст в скобках — отдельное предложение), ищет шаблоны, декор, антитезы выше нормы, разбирает формат чат-ответа.

```bash
python3 skills/antislop-writing/scripts/antislop_lint.py --level 80 draft.md
python3 skills/antislop-writing/scripts/antislop_lint.py --level 100 --mode reply --json < answer.txt
```

Он ловит механику, смысл не понимает. Агент запускает его сам, если умеет запускать Python. Без Python агент проходит тот же список вручную.

## Платформы

| Платформа | Навыки | «Всегда включено» | Что проверено |
|---|---|---|---|
| Claude Code | `~/.claude/skills` или плагин | блок в `~/.claude/CLAUDE.md` или хук плагина | Установка навыков и плагина в изолированном конфиге, `claude plugin validate --strict`, хук запущен отдельно. Живой сеанс не проверен: сессия Claude истекла |
| Claude Desktop | вкладка Code: как Claude Code; Chat и Cowork: ZIP через Customize → Skills | вкладка Code: `CLAUDE.md`; Chat и Cowork: личные предпочтения | Структура ZIP и валидатор. В аккаунт не загружалось |
| OpenCode | `~/.agents/skills`, `.agents/skills` | `AGENTS.md` (читает и `~/.claude/CLAUDE.md`) | **Живой запуск:** навыки найдены, уровень из `AGENTS.md` прочитан |
| Codex | `~/.agents/skills` | `~/.codex/AGENTS.md` (или `AGENTS.override.md`) | Пути по документации. Codex не запускался |
| Gemini CLI | `~/.agents/skills` (по данным `skills`) | `~/.gemini/GEMINI.md` | Пути по документации. Не запускался |
| Windsurf | да (по данным `skills`) | `~/.codeium/windsurf/memories/global_rules.md` | Пути по документации. Не запускался |
| Cursor, GitHub Copilot | да (по данным `skills`) | нет глобального файла: `--project` пишет `AGENTS.md` | Не запускались |
| Остальные агенты со Skills | через `npx skills` | `AGENTS.md` в проекте | Не запускались |
| ChatGPT, веб Claude и Gemini | нет | вставить `prompts/mini.md` | Размер проверен тестом |

Установщик проверен на изолированной домашней папке с каталогами Claude Code, Codex, OpenCode и Gemini CLI: девять навыков на месте, ссылки `statya` → `../redaktura/references/…` работают, удаление чистое. Строки «не запускался» вы можете проверить и сообщить в issue.

Цена в контексте (оценка `claude plugin details`): описания девяти навыков держат около 1,7 тыс. токенов за сессию. Вызов `antislop-writing` добавляет около 1,5 тыс. Правило «всегда включено» — около 1,8 тыс. знаков.

## Что показала проверка

Четыре задачи, по одному прогону на условие: [`examples/eval`](examples/eval/README.md). С навыком в чатовом ответе исчезают заголовки (8 → 0), жирные выделения (10 → 0) и итоговые резюме, текст короче на 17–32%. Модель перестаёт дописывать пользу, о которой её не просили («их удобно искать по дате»). Первый прогон на уровне 100 выявил слабость (глоссарий и повтор шага), правило исправлено, прогон повторён.

Ограничения проверки. По одному прогону на условие. Линтер написан по тем же правилам, что и навык, и мерит их соблюдение, а не пользу читателю. Читатели не участвовали. Модель одна.

## Ограничения

- Это не сертификация. Ни ASD-STE100, ни ГОСТ Р 58049-2017 никакой навык не подтверждает. Для русского нет закрытого словаря. ГОСТ описывает перевод авиационной документации, раздел 8.2 — ближайший аналог STE, не его эквивалент.
- Это не обход детекторов ИИ. Они ненадёжны. Цель — читаемый текст.
- Модель может нарушить правило. Навык повышает вероятность, не гарантирует. Для критичных текстов читайте результат.
- Строгие уровни сушат текст. Для живого текста понижайте уровень. Проза и стихи в зону применения не входят.
- Правила не заменяют знание предмета. Слабый факт не станет сильнее от короткого предложения.
- Если у вас уже стоят `redaktura` и другие навыки из оригинала, наша установка заменит их копиями того же содержания.
