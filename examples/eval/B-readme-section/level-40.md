## Откат миграции

Перед откатом сделайте бэкап базы. Откат удаляет данные из колонок, которые добавила миграция 0005.

Чтобы вернуться к миграции 0004, выполните:

```bash
python manage.py migrate shop 0004
```

В команде `shop` — имя приложения, `0004` — номер миграции, к которой нужно вернуться.
