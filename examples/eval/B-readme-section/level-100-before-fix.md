## Откат миграции

Термины:

- Откат — возврат базы к более ранней миграции.
- `shop` — имя приложения.
- `0004` — номер миграции, к которой нужно вернуться.

Сделайте бэкап базы перед откатом. Откат на `0004` удаляет данные из колонок, добавленных в миграции 0005.

1. Сделайте бэкап базы.
2. Выполните команду:

   ```bash
   python manage.py migrate shop 0004
   ```

3. Чтобы вернуться к другой миграции, замените `shop` на имя своего приложения. Замените `0004` на номер нужной миграции.
