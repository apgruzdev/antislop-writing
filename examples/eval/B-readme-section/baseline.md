## Откат миграции

Чтобы откатить миграции приложения `shop` до миграции `0004`, выполните:

```bash
python manage.py migrate shop 0004
```

Здесь:

- `shop` — имя приложения;
- `0004` — номер миграции, к которой нужно вернуться.

### Перед откатом

Обязательно сделайте бэкап базы данных.

> **Внимание:** откат удаляет данные из колонок, добавленных в миграции `0005`. Эти данные будут потеряны.
